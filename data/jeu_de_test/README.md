# Jeu de test (fiche : livrable 4)

Exigé : **au moins 2 offres et 5 candidatures fictives** (CV, diplôme et CIN fictifs), dont **un cas avec une incohérence volontaire** entre les documents.

```
jeu_de_test/
├── offres/                       une offre par fichier
└── candidats/
    ├── candidat_1/               cv, diplome, cin
    ├── candidat_2/
    ├── candidat_3/
    ├── candidat_4/
    └── candidat_5/               proposition : le cas avec incohérence volontaire
```

## Règles
- **Aucune vraie donnée personnelle**, même modifiée. Les CIN et diplômes sont des modèles fictifs, clairement marqués « Document fictif ».
- Nommer les fichiers de façon identique pour chaque candidat : `cv.pdf`, `diplome.png`, `cin.png`.
- Documenter dans ce fichier ce que contient chaque candidat et ce que les agents doivent trouver.
